# AutoJs6 Plugin: YOLO NCNN 0.1.0

> Draft only. This revision is not production signed or published.

## Compatibility

- AutoJs6 minimum version code: `5275`
- Provider protocol: YOLO AIDL/TaggedWire `1.0`
- Android SDK: minimum 24, target 36
- ABI: `arm64-v8a` only
- Provider process: isolated app process `:provider`

## Runtime scope

- Backend: NCNN `20260526`
- Device: CPU only
- Task: object detection
- Pixel input: `RGBA_8888`
- Model format: NCNN parameter and binary descriptors plus Model Manifest v1
- Decoder: `ultralytics-detect`
- Compatibility fixture: YOLO11n detect; compatible custom class counts are
  manifest-driven

Vulkan, other ABIs, segmentation, pose, OBB, tracking, queued inference, and
unknown decoders are unsupported and fail closed. Installing the Provider does
not enable YOLO in AutoJs6; the Host retains explicit selection, trust,
authorization, and enable state.

## Distribution boundary

The APK includes the plugin MPL-2.0 text, NCNN's complete license/notices,
third-party notice index, and pinned NCNN provenance. It includes no model
weights, training data, exporter runtime, or validation image. Models are
external user-selected resources and keep their original license conditions.

## Evidence still required for publication
